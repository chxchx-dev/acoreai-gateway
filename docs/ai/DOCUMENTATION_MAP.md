# Mapa documental

| Necesidad | Fuente responsable |
| --- | --- |
| Entrada y límites de agentes | `AGENTS.md` |
| Adaptación para Claude Code | `CLAUDE.md` |
| Arquitectura vigente | `docs/ARCHITECTURE.md` |
| Reglas transversales | `docs/RULES.md` |
| Decisiones | `docs/DECISIONS.md` |
| Riesgos | `docs/RISKS.md` |
| Trabajo futuro | `docs/BACKLOG.md` |
| Estado operativo corto | `docs/ai/PROJECT_STATE.md` |
| Procedimientos por cambio | `docs/ai/workflows/` |
| Alcance de roles | `docs/ai/agents/` |
| Diagnóstico estructural | `docs/ai/scripts/doctor.sh` |
| Comportamiento efectivo | código, contratos, migraciones y pruebas |

No se crean documentos paralelos para la misma responsabilidad. Una regla
específica de módulo puede vivir junto al código si enlaza desde este mapa o
desde `AGENTS.md` y no contradice las reglas raíz.

# Workflow: release

1. Confirma alcance, migraciones, compatibilidad y plan de rollback.
2. Ejecuta lint, build, pruebas y doctor en un entorno reproducible.
3. Comprueba health checks, smoke tests, logs, métricas y dependencias
   externas.
4. Revisa que no haya secretos, artefactos ni estado local en el cambio.
5. Documenta versión, evidencia, riesgos aceptados y rollback.

Entrega: checklist de evidencia, cambios operativos y procedimiento de vuelta.

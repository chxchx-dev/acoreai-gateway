# Workflow: sincronización documental

1. Identifica la única fuente responsable del dato.
2. Corrige el documento canónico y elimina duplicados o referencias retiradas.
3. Actualiza el índice, estado, decisión, riesgo o backlog que corresponda.
4. Comprueba enlaces relativos, doctor y `git diff --check`.

Entrega: fuentes actualizadas, duplicados retirados y validaciones ejecutadas.

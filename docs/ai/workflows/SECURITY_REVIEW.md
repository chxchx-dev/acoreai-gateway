# Workflow: revisión de seguridad

1. Define superficie, actor, activos y límites de la revisión.
2. Comprueba autenticación, autorización, tenancy, validación, secretos,
   exposición de datos, logs y dependencias.
3. Prueba abuso y casos negativos reproducibles.
4. Registra hallazgos con impacto, evidencia, mitigación y estado.
5. Verifica el cierre con pruebas y doctor; no edites código desde el rol de
   revisión salvo autorización explícita.

Entrega: alcance, hallazgos priorizados, evidencia, mitigaciones y pendientes.

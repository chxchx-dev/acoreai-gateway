# Rol: security-reviewer

- **Objetivo:** auditar abuso, permisos, secretos y exposición de datos.
- **Debe leer:** reglas, arquitectura, workflow de seguridad y superficies
  afectadas.
- **Puede:** ejecutar comprobaciones y documentar hallazgos reproducibles.
- **No puede:** editar por defecto, aceptar secretos en el repositorio o
  sustituir una prueba por una afirmación.
- **Terminado:** alcance, impacto, evidencia, mitigación y estado de cada
  hallazgo están documentados.

# Rol: implementer

- **Objetivo:** entregar un slice funcional y verificable.
- **Debe leer:** estado, reglas, arquitectura, workflow aplicable y módulo
  afectado.
- **Puede:** editar código, pruebas y documentación necesaria dentro del
  alcance.
- **No puede:** saltarse límites de módulo, exponer configuración privada o
  ampliar el alcance sin decisión.
- **Terminado:** implementación, casos negativos, pruebas y documentación
  sincronizada pasan las validaciones.
